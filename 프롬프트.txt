5. 추론하고 행동하기
[최근 3개월간 웹사이트 방문자 데이터를 분석해야해.
먼저, 데이터를 로드하고 기본적인 통계를 확인해.
그 다음, 페이지별 방문횟수를 집계하는 코드를 짜서 실행하고
그 결과를 바탕으로 Top5 페이지 목록과 각 페이지의 특징을 보도해줘.]


문제해결을 위해 다음과 같은 프로세스를 사용해
1. 3명의 서로 다른 관점을 가진 전문가가 이 문제에 접근한다.
2. 각 전문가는 자신만의 독특한 접근법을 사용한다.
3. 매 단계마다 각자의 생각을 1단계씩 공유한다.
4. 다른 전문가들의 의견을 듣고 자신의 방향을 조정할 수 있다.
5. 잘못된 방향으로 가고 있다고 판단되면 그 전문가는 탈락한다.
6. 최종적으로 가장 유망한 해결책을 도출한다.

Edu-Record 배포 가이드
이 문서는 Edu-Record 프로젝트를 무료로 쉽게 배포하는 방법을 단계별로 설명합니다. 가장 추천하는 방법은 Netlify를 사용하는 것입니다.
1단계: 프로젝트 빌드하기 (준비)
배포하기 전에 코드를 최적화된 파일로 변환해야 합니다.
VS Code 터미널을 엽니다 (Ctrl + `).
아래 명령어를 입력하고 엔터를 누릅니다:
npm run build
명령어가 완료되면 프로젝트 폴더 왼쪽에 dist 라는 새로운 폴더가 생겼는지 확인하세요. 이 폴더가 배포할 실제 파일들입니다.
2단계: 배포하기 (Netlify 사용)
가장 쉽고 빠른 방법인 '드래그 앤 드롭' 방식을 사용하겠습니다.
웹 브라우저에서 Netlify Drop 사이트로 이동합니다. (로그인이 필요할 수 있습니다. GitHub 계정 등으로 가입/로그인하세요.)
로그인 후 대시보드나 'Sites' 메뉴로 이동합니다.
화면에 "Drag and drop your site output folder here" 라는 영역이 보일 것입니다.
방금 생성한 dist 폴더를 마우스로 끌어서 저 영역에 놓으세요. (폴더 전체를 끌어다 놓아야 합니다.)
업로드가 완료되면 즉시 웹사이트 주소가 생성됩니다.


너는 나의 '스마트 일정 관리 비서'야. 내가 문서(PDF, 이미지 등)를 업로드하면 다음 절차를 엄격히 따라줘.
1. 분석 및 추출 단계: 업로드된 파일의 내용을 정밀하게 분석해서 날짜, 시간이 포함된 모든 '일정', '할 일', '약속', '마감일'을 찾아줘.
2. 목록 제시 단계 (매우 중요): 절대로 바로 캘린더에 저장하지 마. 먼저 아래 형식으로 정리해서 번호를 붙여 나에게 보여줘.

장소: (없으면 생략)
내용: (간략 요약)
(제목) 치과 검진
일시: ...
3. 사용자 선택 및 실행 단계: 목록을 보여준 뒤 "어떤 일정을 캘린더에 추가할까요?"라고 물어봐. 내가 "1번이랑 3번 추가해줘"라고 하면, 그때 Google Calendar 확장 프로그램을 사용하여 실제 캘린더에 일정을 등록해.
4. 예외 처리: 날짜나 시간이 명확하지 않은 항목은 "시간 확인 필요"라고 표시해서 알려줘.
